LGPL components in this NEXT HMI distribution
=============================================

This build depends on two libraries licensed under the GNU Lesser General
Public License. They are used unmodified:

  asyncua   OPC-UA client            LGPL-3.0-or-later
  zeroconf  LAN peer discovery       LGPL-2.1-or-later

Replaceability
--------------
Both libraries ship in this folder ("lgpl/") as loose, replaceable package
directories rather than frozen inside the executable. You may substitute your
own build of either package by replacing its directory here; the application
adds this folder to its module search path at startup. This satisfies the
LGPL's requirement that the LGPL-covered component remain replaceable in a
combined work.
